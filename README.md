# Context-Genie 🎉

**Context-Genie** is a **FastAPI-powered backend** for intelligent **document-based Q&A**. It leverages **semantic search** and **generative AI** to extract, index, and retrieve contextually accurate answers from **PDF documents** with **page references**. 🌐

---

## 🚀 Features

- **PDF Document Processing**: Extracts and processes content from PDF documents. 📄
- **Semantic Search**: Uses **Sentence Transformers** to create embeddings for efficient document search. 🔍
- **Generative AI**: AI-based question-answering with **Google Generative AI** for context-based responses. 🤖
- **FastAPI Backend**: High-performance REST API powered by **FastAPI** for fast query handling. ⚡
- **FAISS Indexing**: Optimized search using **FAISS** for quick similarity and vector searches. 💡

---

## 📄 Requirements

Here’s a list of the required libraries for running the backend:

- **FastAPI**: Web framework for building modern APIs. 🌐
- **Uvicorn**: ASGI server to run FastAPI applications. 🚀
- **PyMuPDF**: Extract text and metadata from PDF files. 📚
- **Sentence-Transformers**: Embedding sentences for semantic similarity. 🧠
- **FAISS-CPU**: Efficient similarity search for large datasets. ⚙️
- **Google-GenerativeAI**: For generating AI-powered responses. 🤖
